# Security policy

## Supported versions

Security fixes target `main` and the latest prerelease during beta development.
Older prereleases are not maintained separately. Upgrade to the latest
prerelease when a fix is released.

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/jaakkonakaza/apns/security/advisories/new).
Do not disclose vulnerability details in public issues or pull requests.

Include the affected version or commit, Go version, relevant configuration,
expected impact, and a minimal reproduction using synthetic credentials and
payloads. Never include APNs signing keys, certificate private keys, bearer
tokens, device tokens, or notification content from real users.

Reports are handled on a best-effort basis. Response and fix times are not
guaranteed. Use the private report to coordinate a fix and public disclosure.
